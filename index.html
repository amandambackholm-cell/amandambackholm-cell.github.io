En enkel introduktion

Så fungerar Claude Code

En AI-assistent som inte bara svarar på frågor, utan också kan läsa filer, skriva kod och köra kommandon på din dator.

Vad är Claude Code?

Claude Code är ett verktyg från Anthropic där du beskriver vad du vill ha gjort med vanliga ord. Claude tar sedan reda på hur det kan göras och utför arbetet i din projektmapp.

Skillnaden mot en vanlig chatt är att du slipper kopiera text fram och tillbaka. Claude arbetar direkt med dina filer. Du behöver inte heller kunna programmera för att komma igång, även om det hjälper att förstå vad som händer.

Så går det till

Arbetet följer nästan alltid samma mönster:

  1. Du beskriver målet

    Till exempel: ”Skapa en enkel hemsida om min bokklubb.”

  2. Claude sätter sig in i läget

    Claude läser relevanta filer i mappen för att förstå vad som redan finns.

  3. Claude gör jobbet

    Claude skapar och ändrar filer eller kör kommandon. Känsligare steg kräver ditt godkännande först.

  4. Claude kontrollerar resultatet

    Claude kan köra tester eller öppna sidan för att se att allt fungerar och rätta eventuella fel.

  5. Du granskar och styr vidare

    Du tittar på resultatet och säger vad som ska ändras. Sedan börjar samma mönster om.

Ett påhittat exempel

Du: Lägg till en sida med våra öppettider. Claude läser index.html Claude skapar oppettider.html Claude lägger till en länk i menyn Claude: Klart! Sidan är skapad och länkad från menyn. Du: Bra, men gör tabellen lite luftigare.

Du pratar med Claude som med en kollega, och kan rätta kursen när som helst.

Var kan man använda det?

Terminalen

Den ursprungliga versionen, där du skriver direkt på kommandoraden.

Skrivbordsappen

Ett grafiskt gränssnitt som passar bra om du inte är van vid terminalen.

Webbläsaren

Claude arbetar i molnet, utan att något behöver installeras.

Kodredigerare

Tillägg för bland annat VS Code och JetBrains, för dig som redan kodar.

Du behåller kontrollen

Eftersom Claude kan ändra filer och köra kommandon finns det behörigheter. Du väljer vad Claude får göra på egen hand, och Claude frågar innan sådant du inte har godkänt i förväg.

Läs gärna frågorna innan du svarar ja. Claude kan göra misstag, så det är klokt att granska resultatet, särskilt innan något publiceras.

Tips för att komma igång

  • Börja smått. Ett litet, tydligt uppdrag ger snabbt en känsla för hur det fungerar.
  • Berätta varför. Claude gör bättre val om du förklarar syftet och vem resultatet är till för.
  • Ge feedback. Det första förslaget behöver inte vara det sista. Säg vad du vill ändra.
  • Spara instruktioner. I filen CLAUDE.md kan du skriva sådant Claude alltid ska känna till om projektet.
